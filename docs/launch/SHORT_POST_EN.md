## Short version

Cyber Intelligence Radar: a self-hosted intel radar that doesn't just
ask "is this new?" — it asks "what actually changed?"

Tracks the same event across runs, re-surfaces it only on a material
change (KEV listing, new IOC, confirmed exploitation, a fix shipping).
Same idea applied to academic papers. Evidence-checked, not
trust-the-LLM. Apache-2.0.

`pip install -e .` → `cyber-radar demo` — zero API keys needed to see it
work.

https://github.com/4rslanismet/cyber-intelligence-radar

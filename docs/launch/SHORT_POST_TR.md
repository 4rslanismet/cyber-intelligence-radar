# Kısa Gönderi (TR) — Taslak

*X/Twitter, kısa duyuru vb. için. Sadece taslak.*

Cyber Intelligence Radar: self-hosted bir istihbarat radarı — "bu yeni
mi?" diye sormuyor, "gerçekten ne değişti?" diye soruyor.

Aynı olayı çalıştırmalar arasında takip ediyor, sadece gerçek bir
değişiklikte (KEV'e eklenme, yeni IOC, aktif istismar teyidi, düzeltme
yayınlanması) tekrar yüzeye çıkarıyor. Aynı mantık akademik makaleler
için de geçerli. Modele değil kanıta güveniyor. Apache-2.0.

`pip install -e .` → `cyber-radar demo` — çalıştığını görmek için API
anahtarı bile gerekmiyor.

https://github.com/4rslanismet/cyber-intelligence-radar
